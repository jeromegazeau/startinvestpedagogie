# Start Invest Pédagogie

Outils personnels et familiaux, copie autonome des simulateurs d’origine. Ordre : effort d’épargne, allocation globale, répartition ETF. Calculs dans le navigateur, sans transmission ni sauvegarde automatique des saisies.

Adresse du site : https://jeromegazeau.github.io/startinvestpedagogie/.

Pour héberger : créer ou sélectionner le dépôt jeromegazeau/startinvestpedagogie ; déposer le contenu de ce dossier à la racine ; dans Settings > Pages, choisir Deploy from a branch, main, / (root), puis Save. Si l’interface limite le nombre de fichiers par dépôt, procéder en plusieurs lots : fichiers racine, assets, documents, fiches. Ne pas créer un sous-dossier supplémentaire autour d’index.html.

Avec GitHub Free, un site Pages issu d’un dépôt public est accessible publiquement. noindex et robots.txt ne constituent pas une protection ; l’absence d’indexation n’est pas garantie. Pour un accès confidentiel, utiliser plutôt la copie locale hors ligne ou une solution avec authentification.

Ne jamais verser de fichier de séance JSON/CSV, capture de données réelles, relevé bancaire ou identifiant dans ce dépôt. Les exports se conservent uniquement sur l’appareil de la personne. Les modèles et les taux sont datés : vérifier les hypothèses et les règles fiscales avant de les réutiliser. Aucun rendement garanti, aucune recommandation personnalisée.
